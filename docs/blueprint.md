# **App Name**: Webman

## Core Features:

- Request Sending: Send HTTP requests (GET, POST, PUT, DELETE) to specified endpoints with customizable headers and request bodies.
- Request History: Maintain a history of sent requests, allowing users to easily recall and resend previous requests.
- Request Persistence: Automatically save and pre-populate request details (URL, method, headers, body) for future use, enhancing efficiency.

## Style Guidelines:

- Primary color: Dark blue (#1A202C) for the header and main sections.
- Secondary color: Light gray (#EDF2F7) for input fields and backgrounds.
- Accent: Teal (#4DC0B5) for buttons and active states.
- Use a clean, tabbed layout for managing different requests and history.
- Use clear and consistent icons for HTTP methods (GET, POST, PUT, DELETE) and other actions.
